# Contribute

This font is developed using [FontForge](https://github.com/fontforge/fontforge) and then exported to UFO format.

We recommend contributing to the original FontForge `.sfd` files rather than the `.ufo` exports.

**There must be two font files:**

- `SyyUDT-Regular.sfd`:  
  `Syy UDT Regular`, based on **ตัวหนา** used in-game
- `SyyUDS-Regular.sfd`:  
  `Syy UDS Regular`, based on ตัวบาง used in-game

> **⚠️ IMPORTANT:** Whenever you make a change to `SyyUDT`, don't forget to apply the same change to `SyyUDS`.

## Glyph Guidelines

- **Units Per Em:** 1024
- **Width alignment:** Glyphs must pixel-fit at 72 DPI at a point size of 16 or any multiple of 32.
- **Coordinates:** All outlines must use **integer coordinates** — no floating-point values.
- **Extrema points:** Glyphs must have **no missing extrema**; all extreme points must be present.
- **Curve format:** All outlines in the `fore` layer must use **quadratic curves**.
- **Kerning:** Values must be multiples of 32.
- **Overlaps:** When building, overlaps **must be merged** using `--overlaps-backend pathops`.
  - This is not required for source files, which could remain decomposed.
- **Accented characters:** Generate accented characters using `ff_accent.py` when exporting to UFO.
  Do not store generated accented characters in the `.sfd`; only keep characters
  that cannot be generated by the script.

### Minor Guidelines
- **Vendor ID:** [`SyDi`](https://learn.microsoft.com/en-us/typography/vendors/#s)

# Requirements
This font is developed on macOS (and partly on Linux), so it's good to know some basic *nix commands.
The developer is not familiar with other operating system environments and may not be able to provide guidance for them.

- `git`
- FontForge **version: 20230101**  
  *Newer versions have critical bugs and may generate severely corrupted font binaries, which can trigger malware-like behavior or security warnings.*  
  *Although this version has serious bugs too, but they are manageable. Newer versions are strongly discouraged.*
- Python **(recommended version: 3.12.3)**  
  *Some packages in [requirements.txt](requirements.txt) may not be compatible with newer versions.*
- [`pip`](https://pip.pypa.io/en/stable/installation/)  
  *Use a version compatible with your Python installation.*
- [`woff2`](https://github.com/google/woff2)  
  *For Web Font compression*
- [`pngquant`](https://pngquant.org/)  
  *All PNG files in this repository must be compressed*
- [`Cairo`](https://formulae.brew.sh/formula/cairo)  
  *Required if you want to generate test images for OpenType features on macOS.*
- Stable internet connection

# How to Convert SFD to UFO

1. Read the **Cautions** section below before proceeding.
2. Open **File > Generate Fonts**.
3. Select **Unified Font Object (UFO3)**.
4. Output to `SyyUDT-Regular.ufo`
5. Under **Options**, enable **OpenType**.
6. Click **Generate**.

## Cautions

FontForge (tested with version 20230101) may omit or **incorrectly** export certain OpenType features when build as `.ufo`. Especially *Contextual Chaining Substitution* using *By Classes*.

You may need to manually re-add or correct these features in the `.ufo` file.

It is recommended to export to a **new file** rather than overwriting the existing one.
Then compare both files to identify any missing data before deleting the old file.

### Known Issues and Fixes (Source Files)
(*For 1, 2, 3, and 4 : We made some autofix tools — check them out in the [scripts](scripts) folder yourself.*)

Fix common issues:
```
 python ./scripts/fix_ufo.py ./sources/SyyUDT-Regular.ufo   
```

1. Wrong GlifName in .sfd  
    FontForge saves incorrect `GlifName` entries even when the `StartChar` is correct.  
    These broken `GlifName` lines interfere with `.ufo` export and other toolchains.

   **Solution:** **remove** all `GlifName` lines.

   **Steps:**
   - Save and close the file in FontForge.
   - Run this command to wipe all `GlifName` entries:
     ```bash
     python ./scripts/fix_sfd.py ./sources/SyyUDT-Regular.sfd
     ```
   - Reopen the `.sfd` file in FontForge.
   - Export to `.ufo`
2. FontForge export an incorrect `styleMapFamilyName`.  
Update it manually in [sources/SyyUDT-Regular.ufo/fontinfo.plist](sources/SyyUDT-Regular.ufo/fontinfo.plist):
```
    <key>styleMapFamilyName</key>
    <string>Syy UDT</string>
```
3. FontForge omit to export `Really use Typo metrics`.  
Manually add the following to [sources/SyyUDT-Regular.ufo/fontinfo.plist](sources/SyyUDT-Regular.ufo/fontinfo.plist)
```
    <key>openTypeOS2Selection</key>
    <array>
      <integer>7</integer> 
    </array>
```
4. FontForge omit to export `StdVW` and `StdHW`  
Manually add the following to [sources/SyyUDT-Regular.ufo/fontinfo.plist](sources/SyyUDT-Regular.ufo/fontinfo.plist)
```
    <key>postscriptStemSnapH</key>
    <array>
      <integer>80</integer>
    </array>
    <key>postscriptStemSnapV</key>
    <array>
      <integer>90</integer>
    </array>
```
5. FontForge export wrong `features.fea`  
Manually edit to this in both ufo
```
lookup ccmpThaiLowlineAbove {
  lookupflag 0;
    sub  \uni0E48'lookup ThaiLowlineTone1  \uni0331'lookup ThaiLowlineTone1  ;
    sub  \uni0E49'lookup ThaiLowlineTone2  \uni0331'lookup ThaiLowlineTone2  ;
    sub  \uni0E4A'lookup ThaiLowlineTone3  \uni0331'lookup ThaiLowlineTone3  ;
    sub  \uni0E4B'lookup ThaiLowlineTone4  \uni0331'lookup ThaiLowlineTone4  ;
} ccmpThaiLowlineAbove;

lookup ccmpThaiBindhuSraBelowReordering {
  lookupflag 0;
    sub  \uni0E38'lookup ThaiLowlineSraUReordering  \uni0331'lookup ThaiLowlineSraUReordering  ;
    sub  \uni0E39'lookup ThaiLowlineSraUUReordering  \uni0331'lookup ThaiLowlineSraUUReordering  ;
    sub  \uni0E38'lookup ThaiBindhuSraUReordering  \uni0E3A'lookup ThaiBindhuSraUReordering  ;
    sub  \uni0E39'lookup ThaiBindhuSraUUReordering  \uni0E3A'lookup ThaiBindhuSraUUReordering  ;
} ccmpThaiBindhuSraBelowReordering;
```

# How to build
This repository primarily uses builds from the `.ufo` source
to double-check that the final font works correctly.

## Initial Setup
Run the following commands to set up the environment:
```
git clone https://github.com/Plaenithaan/Syy-BENEATHPOEM.git --recursive
cd Syy-BENEATHPOEM
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
For future sessions, simply activate the virtual environment with:
```
source .venv/bin/activate
```
## Building the Font
A preconfigured build script is available at [sources/build.sh](sources/build.sh). To use it, run:
```
bash sources/build.sh
```
If your internet connection is unstable, you can `--skip-network` the [Font Bakery](https://github.com/fonttools/fontbakery) quality check by running:
```
bash sources/build.sh --skip-network
```
To also run Diffenator 2 : compare hinted vs unhinted TTF fonts (HTML output, ~2–3 min), run:
```
bash sources/build.sh --diffenator
```

Alternatively, you can build step-by-step as shown below.
### Using fontmake
You can build the font from the .ufo source using [fontmake](https://github.com/googlefonts/fontmake):
```
fontmake ./sources/SyyUDT-Regular.ufo -o ttf --output-dir ./fonts/unhinted/ttf/ --overlaps-backend pathops
```
### Using FontForge
Alternatively, you can also build the font manually by opening the `.sfd` file with [FontForge](https://github.com/fontforge/fontforge), or via command line:
```
fontforge -lang=ff -c 'Open("./sources/SyyUDT-Regular.sfd"); Generate("./fonts/unhinted/ttf/SyyUDT-Regular.ttf", "", 0x84)'
```

### Hinting
Use `gftools autohint` (bundled with the latest `ttfautohint`) to hint the TTF:
```
gftools autohint ./fonts/unhinted/ttf/SyyUDT-Regular.ttf  -o ./fonts/ttf/SyyUDT-Regular.ttf --args "-X -"
gftools fix-hinting ./fonts/ttf/SyyUDT-Regular.ttf
rm ./fonts/ttf/SyyUDT-Regular.ttf
mv ./fonts/ttf/SyyUDT-Regular.ttf.fix ./fonts/ttf/SyyUDT-Regular.ttf
```
To avoid inconsistent heights, use the argument `--args "-X -"` to disable x-height snapping.

### Generating `.woff2`
Use [woff2_compress](https://github.com/google/woff2) to convert `.ttf` files to `.woff2`:
```
woff2_compress ./fonts/unhinted/ttf/SyyUDT-Regular.ttf; 
mv ./fonts/unhinted/ttf/SyyUDT-Regular.woff2 ./fonts/unhinted/webfonts/SyyUDT-Regular.woff2
```
```
woff2_compress ./fonts/hinted/ttf/SyyUDT-Regular.ttf; 
mv ./fonts/ttf/SyyUDT-Regular.woff2 ./fonts/webfonts/SyyUDT-Regular.woff2
```

### Checking the quality of font
Use [Font Bakery](https://github.com/fonttools/fontbakery):
```
fontbakery check-googlefonts -F --succinct --json out/fontbakery/fontbakery-report.json fonts/ttf/*.ttf  --html out/fontbakery/fontbakery-report.html --ghmarkdown out/fontbakery/fontbakery-report.md --configuration fontbakery.yaml
```
